# G-STEEL READERS - リーディング没入タイマー ＆ 読書ノート システム設計図（完成版）

## 📌 概要・コンセプト

本システムは、ユーザーが読書に完全没入するための**PCブラウザ専用30分（可変対応）タイマー ＆ 読書ノート統合システム**です。
G-SHOCK（G-STEEL / MT-Gシリーズ）の重厚・武骨で洗練されたメタリック世界観をベースにし、余計な飾りや複雑な設定画面を完全に排したシンプルな計器UIとして構築されています。

---

## 🛠 主要機能仕様

### 1. デザイン ＆ UI構成（G-SHOCKメタリックテーマ）
- **外観**: ガンメタリック・スチール質感のグラデーション、切削ベゼルビス、重厚なアナログ針、ミリタリー刻印。
- **キャンバスアナログ時計**: HTML5 Canvas (2D) による30分（可変時間対応）のクロノグラフ針、動的目盛り、ネオン蓄光ライン描画。
- **サブ液晶ディスプレイ (LCD)**: デジタルタイマー文字、フェーズインジケーター、切替カウントダウンのセグメント表示。

### 2. タイマー時間設定 ＆ 動的スケール
- **初期設定**: 30分（1800秒）固定。
- **時間指定（音声・画面操作）**:
  - 音声で「5分」「10分」「15分30秒」「20分」などと指定可能。
  - 画面上のクイックプリセットボタン（5分 / 10分 / 15分 / 30分）および分・秒入力フォームからの設定。

### 3. 動的インターバル（BGM切替 ＆ 励ましボイス）
- **26分以上指定の場合（例: 30分タイマー）**:
  - インターバル: **10分単位（600秒）**
- **25分以下指定の場合（例: 5分, 15分30秒, 20分タイマー）**:
  - インターバル: **5分単位（300秒）**
- **フェーズ構成**:
  - **Phase 1**: カフェ・アコースティックサウンド（ウォームアップ）
  - **Phase 2**: 雨音 ＋ Lo-Fiジャズアンビエント（ディープゾーン）
  - **Phase 3**: 深層没入ピアノ ＋ カフェノイズ（ピーク没入）
- **モチベーションボイス（励まし）**:
  - インターバルごとに画面発光 ＋ 音声ナレーション（例：「いい感じ！○分経過、集中ゾーンに入ったよ」）。

### 4. 音声ハンズフリーコントロール (Voice Control)
- **Web Speech API (`SpeechRecognition`) 搭載**:
  - 「スタート」「開始」「ストップ」「停止」「リセット」「終わり」などの声に反応。

### 5. 30分終了時の労い ＆ 読書ノート自動問いかけ・音声入力
- **終了演出**: 重厚なフィニッシュベル（チャイム音）＋「お疲れ様でした！今日読んだ本を記録しましょう。何の本を読みましたか？」と音声で問いかけ。
- **音声認識フォーム入力**: 「太宰治の人間失格、45ページから90ページまで」と声で話すと、自動パースされて書名・著者・ページ数が入力フォームに補完。

### 6. 読書ノート（アーカイブ・振り返り・検索機能）
- **ダッシュボード**: 今月の読書時間、通算読書時間、累計セッション数、記録冊数をリアルタイム集計。
- **検索機能**: 書名・著者名・日付・メモからインクリメンタル絞り込み検索。
- **データ保存**: LocalStorage（永続化）＋ JSONファイルへのバックアップ（保存/復元）。

## 🏗 システムファイル構成

```
timer2/
├── index.html       # メイン画面HTML (タイマー画面 ＆ 読書ノートタブ構造)
├── index.css        # G-SHOCKメタリックデザイン、ネオンLCD、レスポンシブスタイル
├── clock.js         # HTML5 Canvas アナログ時計描画モジュール
├── audioEngine.js   # Web Audio API カフェBGM & 効果音・ベル音生成エンジン
├── voice.js         # Web Speech API 音声認識 & 音声合成（ナレーション）モジュール
├── storage.js       # LocalStorage 読書データ管理 ＆ 統計算出・検索
├── logUI.js         # 読書ノートカードリスト & 統計ダッシュボード描画
├── app.js           # タイマー制御・動的インターバル・全体統括ロジック
├── server.ps1       # Windows標準 PowerShell HTTP サーバー起動スクリプト
└── 設計図.md        # 完成版システム設計図（本ファイル）
```

## 🚀 実行・動作環境

- **対応ブラウザ**: PCブラウザ（Google Chrome, Microsoft Edge など）
- **動作方法**:
  1. ローカルサーバー経由: `http://localhost:8080/`
  2. 直ファイル起動: `index.html` をブラウザで直接オープン
