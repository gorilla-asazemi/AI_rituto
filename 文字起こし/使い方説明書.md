# 🎙️ かんたんローカル文字起こしツール 取扱説明書

開発やプログラミングの知識が一切なくても、**完全無料・インストール不要・安全なローカル環境**で音声ファイルの文字起こしができるツールの使い方です。

---

## 🌟 ツールの特徴
1. **完全無料・無制限**：APIキーの取得や課金登録は一切不要です。
2. **完全ローカル処理**：音声ファイルが外部サーバーに送信されないため、個人情報や機密音声も安全です。
3. **ドラッグ＆ドロップ対応**：MP3, M4A, WAV, AAC, MP4 などの音声・動画ファイルを画面に置くだけ。
4. **ワンクリック保存**：文字起こししたテキストをワンクリックでコピー、または `.txt` や `.md`（マークダウン）ファイルとして保存できます。
5. **マイク入力対応**：自分の声をリアルタイムに文字起こしするメモツールとしても使えます。

---

## 🚀 使い方（かんたん3ステップ）

### ステップ1：ツールを開く
- フォルダ内にある **`起動する.bat`** または **`index.html`** をダブルクリックします。
- ブラウザ（Google Chrome または Microsoft Edge）で文字起こし画面が起動します。

### ステップ2：音声ファイルを読み込む
- 文字起こししたい音声ファイル（スマホの録音データ `.m4a` や `.mp3` など）を、画面中央の**オレンジ色の枠の中にドラッグ＆ドロップ**します。
- （または枠をクリックしてファイルを選びます）

### ステップ3：文字起こしを開始する
- 「**文字起こしを開始**」ボタンを押します。
- 音声が再生され、話している内容が下のテキストエリアにリアルタイムでどんどん書き出されます。
- 終わったら「**コピー**」や「**.txt 保存**」「**.md 保存**」を押して活用してください。

## 💡 コツ・トラブルシューティング
- **文字起こしが途中で止まる場合**：再生が一時停止していないか確認し、もう一度「文字起こしを開始」を押してください。
- **推奨ブラウザ**：Google Chrome または Microsoft Edge が最も高精度・高速に動作します。
